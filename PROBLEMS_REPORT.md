## ПРИЧИНЫ ПРОБЛЕМ:

### Проблема 1: 405 ошибки
**Коренная причина:** Неправильные URL
```
НЕПРАВИЛЬНО (было): /courier
ПРАВИЛЬНО (должно быть): /api/v1/courier
```
API сервер ожидал полный путь с /api/v1

### Проблема 2: 400 при отмене заказа
**Коренная причина:** Неправильный формат JSON
```
НЕПРАВИЛЬНО: {"track": 123456} (число)
ПРАВИЛЬНО: {"track": "123456"} (строка)
```

### Проблема 3: Ошибки компиляции
**Коренная причина:** Человеческий фактор при копировании кода
- Дублирование аннотаций
- Неправильное количество скобок
