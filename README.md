# SPRINT_7: Тестирование API Ez-scooter

## 🚨 ВЫЯВЛЕННЫЕ И РЕШЕННЫЕ ПРОБЛЕМЫ

### 🔴 Критические проблемы (блокирующие):

1. **405 Ошибки (Method Not Allowed)**
   - **Описание:** 14 тестов падали с ошибкой "Expected status code <201> but was <405>"
   - **Причина:** Отсутствовал префикс /api/v1 в URL
   - **Решение:** Добавлен BASE_PATH в Config.java

2. **400 Ошибки при отмене заказа**
   - **Описание:** 4 теста падали при отмене заказа
   - **Причина:** Неправильный формат поля track (число вместо строки)
   - **Решение:** Изменен формат JSON в OrderApi.java

### 🟡 Проблемы компиляции:

3. **Ошибки компиляции в тестах**
   - **Описание:** Не компилировались CourierCredentialsTest.java и OrderTest.java
   - **Причины:** Дублирование @After аннотаций, лишние скобки
   - **Решение:** Исправлена структура файлов

### 🟢 Предупреждения:

4. **Предупреждения IDE о неиспользуемых методах**
   - **Описание:** 7 предупреждений "Method is never used"
   - **Решение:** Удалены неиспользуемые методы или добавлены @SuppressWarnings
