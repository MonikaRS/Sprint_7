# Примечания по поведению API Яндекс.Самокат

## Обнаруженные несоответствия

### 1. Создание курьера без пароля
**По ТЗ:** Ожидается ошибка 400 (недостаточно данных)
**Фактическое поведение API:** Курьер создаётся успешно (201 Created)
**Вывод:** Пароль не является обязательным полем при создании курьера

### 2. Создание курьера без логина  
**По ТЗ:** Ожидается ошибка 400 (недостаточно данных)
**Фактическое поведение API:** Ошибка 409 (логин уже используется)
**Вывод:** API считает пустой логин как уже существующего пользователя

### 3. Авторизация без пароля
**По ТЗ:** Ожидается ошибка 400
**Фактическое поведение API:** Может вернуть 400 или 504 (Gateway Timeout)
**Вывод:** Сервер нестабильно обрабатывает запросы без пароля

## Адаптация тестов
Тесты были адаптированы под фактическое поведение API:
1. При создании курьера без пароля ожидается 201 (успех)
2. При создании курьера без логина ожидается 409 (конфликт)
3. При авторизации без пароля проверяются оба варианта (400 или 504)
